# Publication kit (draft)

Repository: https://github.com/dodozg/application-agent-manifest

Suggested description: **A discussion draft for application-supplied AI operator guidance, interface discovery, and verifiable outcome claims.**

Suggested first public post:

> What if every installed application shipped a small, version-matched package for AI agents? An Application Agent Manifest would point to supported interfaces and operator guidance, then specify what observable evidence is needed before an agent claims success. MCP exposes tools; Agent Skills carry procedures; this proposal links those pieces to the installed app and its version. I have drafted a format, a fictional example and a structural validator. Feedback is welcome on installer-based discovery, trust boundaries and interoperable evidence. https://github.com/dodozg/application-agent-manifest

Attribution: initiated by dodozg. Do not call this an official standard or imply endorsement by MCP, Agent Skills or application vendors. A short discussion post pointing to the repository is more useful than posting this proposal into an unrelated issue tracker.

Suggested initial outreach: relevant maintainers of agent interoperability projects, CAD automation communities, and software vendors' developer forums. Send targeted, factual notes only after selecting the recipients and publication channel.
