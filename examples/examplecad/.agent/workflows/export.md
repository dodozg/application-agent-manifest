# Export a neutral model

1. Record the source document identifier and revision.
2. Work from a copy when the session may save changes; do not overwrite the original.
3. Request a rebuild and capture status and diagnostics. Stop and report failures.
4. Invoke the host-resolved exporter. Capture its reported output format.
5. Confirm the file exists, record its byte count and digest, and check that the exporter reported the expected format. A successful export alone does not prove that the geometry is correct.
6. Report source, output, each check's observation and any unknown status.
